# Flask demo — Landing sobre serpientes

Instrucciones rápidas para ejecutar la app localmente.

1. Crear entorno virtual (Windows PowerShell):

```powershell
pip install flask
```

2. Ejecutar la aplicación:

```powershell
python app.py
```

La app quedará disponible en http://127.0.0.1:5000/ y la ruta del chatbot en `/chatbot`.

Si quieres que integre tu chatbot existente, pásame la URL o el código del cliente y lo incorporo.
